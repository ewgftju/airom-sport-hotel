# AIROM Sport Hotel

Сайт бюджетной гостиницы AIROM Sport Hotel в Атырау.

**Адрес:** г. Атырау, ул. Виссариона Белинского, 16а

## Основные разделы

- номера и оснащение;
- питание для команд;
- условия для команд и организаций;
- временные визуализации номеров до получения реальных фотографий;
- стоимость и бронирование;
- контакты и маршрут в 2GIS.

Сайт разработан на Next.js и адаптирован для размещения на Vercel.

## Локальный запуск

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
npm run start
```
